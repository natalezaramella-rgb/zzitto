## 5. Funzionalità con restrizioni (Opzioni di invio)

Un'app WinUI 3 impacchettata come MSIX desktop dichiara la funzionalità con restrizioni `runFullTrust`. Partner Center
chiede una motivazione. Testo proposto (inglese, come richiesto dal modulo):

> Zzitto is a packaged Win32 desktop app built with the Windows App SDK (WinUI 3). runFullTrust is required to run as a
> desktop process that stays in the notification area, registers a global keyboard shortcut, uses UI Automation to locate
> the focused text field in other applications and inserts dictated text there with UI Automation or SendInput (clipboard
> fallback). Speech recognition and text correction run locally in a native library shipped in the package; no data leaves
> the device, and the app does not require administrator privileges.

Se l'agente C aggiunge altre funzionalità con restrizioni (es. avvio automatico con `windows.startupTask`, che non è
ristretta), aggiornare questa sezione.
